# 🏡 Oasis Interior Design

A modern, visually immersive website designed for a luxury interior design studio. The project focuses on **high-quality visual storytelling, smooth animations, responsive design, and user engagement**, creating a premium digital experience for showcasing interior design work.

## ✨ Features

* 🎨 Modern and premium interior design interface
* 📱 Fully responsive design across desktop, tablet, and mobile
* ⚡ High-performance and optimized web experience
* 🖼️ Image-focused layouts for showcasing interior projects
* 🎬 Smooth page transitions and animations
* 🧭 Intuitive navigation and user-friendly interface
* 📩 Call-to-action sections designed to improve user engagement
* ✨ Interactive UI elements powered by animations

## 🛠️ Tech Stack

* **React.js** – Component-based UI development
* **Next.js** – Framework for performance and routing
* **Tailwind CSS** – Responsive and utility-first styling
* **Framer Motion** – Smooth animations and transitions
* **Vercel** – Deployment and hosting

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/smriti1008/Interior-design.git
```

### 2. Navigate to the project directory

```bash
cd Interior-design
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🎯 Project Goals

The main goal of Oasis Interior Design was to build a **premium, visually engaging web experience** rather than a conventional static website.

The project emphasizes:
